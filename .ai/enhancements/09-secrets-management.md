# Secrets Management

**Приоритет:** MEDIUM
**Оценка:** 1 день
**Категория:** Observability & Reliability

## Цель

Безопасное хранение токенов, паролей и чувствительных данных.

## Проблема

Если в манифестах появятся токены или пароли, они будут в открытом виде в Git.

## Предлагаемое решение

1. Поддержка переменных окружения в манифесте:
```yaml
adapter:
  mode: websocket
  token: ${HA_TOKEN}   # берётся из окружения
```

2. Опциональная интеграция с:
   - `.env` файл (через `python-dotenv`)
   - HashiCorp Vault (для production)
   - Нативными секретами Home Assistant (`secrets.yaml`)

## План реализации

1. Создать `core/secrets.py` — резолвер секретов
2. Расширить загрузчик манифеста для подстановки `${...}`
3. Валидация: запрет на хранение секретов в открытом виде
4. Тесты

## Файлы

- `core/secrets.py`
- `core/models/manifest.py` (поддержка секретов)
- `tests/test_secrets.py`

## Критерии успеха

- [ ] Секреты резолвятся из окружения
- [ ] Валидация блокирует открытые секреты
- [ ] Документация по настройке
- [ ] Покрытие тестами >= 80%
