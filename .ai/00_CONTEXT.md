# AI Context Index

Этот файл — точка входа для ИИ-ассистента. Он описывает структуру harness и правила его использования.

## Как использовать

1. **Прочитать этот файл** (00_CONTEXT.md) — ты сейчас здесь
2. **Изучить файлы по порядку** (01 → 06)
3. **Обновлять файлы** после завершения значимых задач

## Структура файлов

| Файл | Назначение | Частота обновления |
|------|-----------|-------------------|
| `01_PROJECT_STATE.md` | Текущее состояние проекта | После каждой значимой задачи |
| `02_ARCHITECTURE.md` | Архитектурные решения | При изменениях архитектуры |
| `03_ROADMAP.md` | История + планы (машиночитаемый) | После каждой задачи |
| `04_RULES.md` | Жесткие ограничения | Редко, по согласованию |
| `05_WORKFLOW.md` | Алгоритм работы ИИ | Редко |
| `06_QUALITY_CHECKS.md` | Чек-листы качества | При добавлении новых проверок |

## Ключевые принципы

1. **Файлы в `.ai/` — живой документ.** ИИ должна обновлять их после каждой значимой задачи.
2. **Не удалять информацию.** Если что-то устарело — помечать как `[DEPRECATED]`, а не удалять.
3. **Добавлять в Known Issues.** Если ИИ нашла баг или долг — записать в `01_PROJECT_STATE.md`.
4. **Roadmap — единый источник истины.** Все планы и статусы задач — только в `03_ROADMAP.md`.

## Быстрый старт

Новая задача? Следуй алгоритму из `05_WORKFLOW.md`.

Нашла баг? Добавь в `01_PROJECT_STATE.md` → Known Issues.

Завершила фазу? Обнови `03_ROADMAP.md` и запусти `make sync-roadmap`.
