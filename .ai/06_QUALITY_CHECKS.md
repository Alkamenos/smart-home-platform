**Pre-commit хук теперь настроен и запускается АВТОМАТИЧЕСКИ!**

```bash
git config core.hooksPath .githooks  # Уже выполнено ✅
```

**Перед КАЖДЫМ коммитом:**
1. Pre-commit хук автоматически запустит `.ai/scripts/run_checks.sh`
2. Проверит актуальность ROADMAP через `sync_roadmap.py`
3. Заблокирует коммит при любой ошибке

**Если хочешь запустить проверки вручную:**
```bash
.ai/scripts/run_checks.sh
```

**Если скрипт завершается с ошибкой (exit code 1):**
- ❌ **НЕ КОММИТЬ!**
- Исправить все проблемы, которые показывает скрипт
- Запустить скрипт снова
- Коммитить только когда все проверки прошли (exit code 0)

**Для авто-исправления форматирования и импортов:**
```bash
ruff check --fix src/ tests/
ruff format src/ tests/
```

## Автоматические проверки

Запуск всех проверок одной командой:

```bash
.ai/scripts/run_checks.sh
```

### Что проверяется

#### 1. Tests (pytest)
- Все тесты должны проходить
- Покрытие кода >= 80% для новых файлов
- Покрытие критических модулей >= 95%

```bash
pytest tests/ -v --cov=src --cov-report=term-missing --cov-fail-under=80
```

#### 2. Type Checking (mypy)
- Strict mode
- Не должно быть ошибок типизации

```bash
mypy src/ --strict
```

#### 3. Linting (ruff)
- Проверка стиля и потенциальных ошибок
- Правила: E, F, W, I, N, UP, B, A, C4, SIM

```bash
ruff check src/ tests/
```

#### 4. Formatting (black)
- Проверка форматирования кода
- Line length: 100

```bash
black --check src/ tests/
```

#### 5. Import Sorting (isort)
- Проверка сортировки импортов
- Profile: black

```bash
isort --check-only src/ tests/
```

#### 6. Documentation Coverage (interrogate)
- Все публичные функции имеют docstrings

```bash
interrogate src/ -vv
```

## Ручные проверки (перед коммитом)

### Обязательные

- [ ] `ROADMAP.md` обновлен (если задача завершена)
- [ ] `.ai/01_PROJECT_STATE.md` обновлен
- [ ] Нет закомментированного кода
- [ ] Нет `TODO` без ссылки на issue или задачи в roadmap
- [ ] Все `print()` заменены на `logger`
- [ ] Нет hardcoded значений (кроме тестов)
- [ ] Нет импортов `from core import *`

### Архитектурные

- [ ] `core/` не импортирует `adapters/`
- [ ] Все новые файлы имеют `__init__.py` в директории
- [ ] Публичные методы имеют `__all__` в `__init__.py`

### Тесты

- [ ] Новые функции покрыты тестами
- [ ] Имена тестов описывают сценарий
- [ ] Нет зависимостей между тестами
- [ ] Тесты быстрые (< 1 секунды каждый)

## Как интерпретировать результаты

### Все проверки прошли ✅
- Можно коммитить
- Обновить `.ai/01_PROJECT_STATE.md`

### Тесты падают ❌
- Не коммитить
- Исправить тесты
- Запустить снова

### Type errors ❌
- Не коммитить
- Исправить типы
- Запустить `mypy` снова

### Lint warnings ⚠️
- Если возможно — исправить
- Если нет — добавить `# noqa: <code>` с объяснением

## Специфичные проверки для модулей

### Для `core/command_dispatcher.py`
- Все приоритеты сравниваются корректно
- `release()` работает только для правильного `source`
- Middleware вызываются в правильном порядке

### Для `core/event_router.py`
- Маппинг строится для всех устройств из манифеста
- `motion_detected` роутится только при `new_state == "on"`
- `motion_cleared` роутится только при `new_state == "off"`

### Для `core/middleware.py`
- Manual lockout блокирует автоматические команды
- Ручные команды не блокируются
- `ControlTracker` корректно записывает события
