# Contract — Маршруты интерфейса (карта «работа → экран»)

Каждый раздел решает одну работу (FR-001). Один экран — одна задача; дублирование данных
запрещено (FR-002).

| Маршрут | Работа | Что показывает | Источник данных |
|---|---|---|---|
| `/` | Что с домом сейчас | Локации (показания, производные), устройства (факт + автоматы), тревоги, быстрые действия | `GET /api/v1/overview` + `WS /api/v1/ws/events` |
| `/locations/[id]` | Детали локации | Все показания по ролям, производные, динамика | `…/locations/{id}/state`, `…/history` |
| `/devices` | Почему так / управление | Список устройств со состояниями, решениями, блокировками | `GET /api/v1/devices` |
| `/devices/[id]` | Почему так / управление | Прибор, автоматы, поведения, оверрайды, диаграмма, команды | `…/devices/{id}`, `…/diagram`, `…/command` |
| `/journal` | Следствие | Живая лента, фильтры (устройство/локация/уровень/trace), трассировка | `GET /api/v1/events` |
| `/settings` | Настройка | Обзор настроек, переходы к подразделам | — |
| `/settings/sources` | Настройка | Источники HA, сущности, импорт, синхронизация | `…/devices/sources/*` |
| `/settings/devices` | Настройка | Устройства: конфигурация, поведения, доступ | `…/devices/*`, `…/access` |
| `/settings/locations` | Настройка | Локации и роли датчиков | `…/locations` |
| `/settings/manifest` | Настройка | Правка манифеста, ошибки по полям | существующие маршруты манифеста |
| `/system` | Здорова ли система | Готовность, источники, метрики, логи | `/ready`, `/health`, `/metrics`, `GET /api/v1/events` |

## Правила навигации

- Единая верхняя навигация (5 разделов) и единый стиль на всех экранах (FR-002).
- Любой сценарий работ 1–6 — не более чем за два перехода (SC-007).
- Адаптив: ключевые сценарии выполнимы на ширине 360 px (SC-009).
- Язык — русский; идентификаторы (`light.girlianda_terassa`) показываются второстепенно
  (FR-003).
- Разделы «Настройка» и «Система» визуально вторичны (реже используются), но не спрятаны.
- Зарезервированные пути API (`/api/**`, `/health`, `/ready`, `/metrics`) под страницы не
  используются.
