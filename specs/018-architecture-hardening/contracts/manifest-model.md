# Contract: каноническое описание дома

**Feature**: `018-architecture-hardening` | **Version**: 1.0 | **Date**: 2026-11-02

## Назначение

Один документ и одна модель для чтения, проверки, редактирования и исполнения.
Контракт описывает поведение, а не файлы: реализация обязана ему соответствовать,
даже если внутренняя структура изменится.

## Правила

1. **Единственный источник.** Любое чтение и запись описания выполняется через
   каноническую модель. Параллельная схема или вторая доменная модель запрещены.
2. **Схема — производная.** JSON Schema для интерфейса, документации и
   внешних потребителей генерируется из канонической модели; ручная копия
   запрещена.
3. **Неизвестные поля.** По умолчанию отклоняются с путём до поля. Явные
   расширения допускаются только в согласованном пространстве `extensions`.
4. **Атомарность.** Сохранение либо применяет всё, либо не меняет ничего.
   Ошибка не оставляет частично записанный документ.
5. **Совместимость.** Документ прежней версии загружается без потери данных;
   недостающие значения получают задокументированные умолчания.
6. **Один путь проверки.** Интерфейс, CLI и загрузка в рантайм дают одинаковый
   результат на одном и том же документе.

## Обязательные проверки

| Проверка | Ожидание |
|---|---|
| Уникальность идентификаторов мест | отказ с указанием дубля |
| Уникальность приборов | отказ с указанием дубля |
| Ссылки на датчики и приборы | все разрешаются |
| Шаблон поведения | существует в реестре |
| Приоритет поведения | уникален в приборе |
| Версия формата | известна и поддерживается |
| Неизвестное поле | отказ с путём `rooms[0].devices[1].foo` |
| Пустое имя дома/места | отказ |

## Форматы ответов

Успешное сохранение:

```json
{"status": "saved", "warnings": []}
```

Отказ проверки:

```json
{
  "error": {
    "code": "manifest_invalid",
    "message": "Описание дома не принято проверкой",
    "fields": [{"path": "rooms[0].devices[1].hysteresis", "message": "вне диапазона"}],
    "trace_id": "..."
  }
}
```

Потеря состава дома (защита от тихого сокращения) — отдельный код
`manifest_shrink`, а не общая ошибка проверки.

## Запрещено

- Писать манифест моделью, отличной от канонической.
- Игнорировать неизвестное поле молча.
- Возвращать «saved», если рантайм не применил изменение.
- Хранить вторую копию правил проверки в WebUI или CLI.
