# Contract: граница управления

**Feature**: `018-architecture-hardening` | **Version**: 1.0 | **Date**: 2026-11-02

## Назначение

Определить, кто и при каких условиях может менять дом, и что происходит при
отказе. Контракт применяется ко всем интерфейсам: Web UI, HTTP API, CLI,
Home Assistant ingress.

## Источники доверия

| Источник | Когда доверяется | Как проверяется |
|---|---|---|
| Доверенная домашняя сеть | адрес входит в настроенные подсети | адрес запроса, не заголовок |
| Home Assistant ingress | запрос пришёл из доверенного прокси-диапазона | адрес прокси; имя — только для отображения |
| Bearer-токен (API/CLI) | токен совпал | сравнение постоянного времени |

**Пароль приложения не требуется** (решение владельца 02.11.2026).  
**Запрещено**: выводить права из `X-Is-Admin`, `X-User-ID` или любого другого
заголовка, присланного клиентом напрямую.

## Роли

| Роль | Может |
|---|---|
| owner | всё: описание, команды, доступы, публикация |
| guest | просмотр; команды по выданному доступу |
| automation | команды в рамках поведения |
| monitor | `/health`, `/ready`, `/metrics` |

## Allowlist без доверенного источника

- `GET /health`
- `GET /ready`
- `GET /metrics`
- статические файлы интерфейса

Всё остальное — default deny.

## Матрица (обязательная)

| Операция | Недоверенный | monitor | guest | owner (LAN/ingress) |
|---|---|---|---|---|
| Чтение состояния дома | deny | deny | allow | allow |
| Изменение описания | deny | deny | deny | allow |
| Команда прибору | deny | deny | по доступу | allow |
| Публикация панели | deny | deny | deny | allow |
| Выдача доступа | deny | deny | deny | allow |
| `/health`, `/ready`, `/metrics` | allow | allow | allow | allow |

## Ответы

| Ситуация | Код | Тело |
|---|---|---|
| Источник вне доверенной сети | 403 | `{"error": {"code": "forbidden", ...}}` |
| Идентичность есть, прав нет | 403 | `{"error": {"code": "forbidden", ...}}` |
| Подделанный признак прав | 403 | как `forbidden`, без раскрытия деталей |
| Доверенный прокси не подтверждён | 403 | как `forbidden` |

Каждый отказ пишется в журнал: источник, операция, причина, `trace_id`.
Секреты и внутренние пути в ответ не попадают.

## Остаточный риск

Любой хост в доверенной сети действует от имени владельца — это принятое
решение. Компенсация: сегментация сети, firewall, запрет проброса порта наружу.

## Запрещено

- Защищать маршруты по одному и забывать новые: middleware глобальный.
- Считать `localhost` достаточной защитой.
- Возвращать 200 на отклонённую операцию.
- Логировать токены, cookie и пароли.
