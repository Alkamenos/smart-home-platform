# Contract: воспроизводимый артефакт поставки

**Feature**: `018-architecture-hardening` | **Version**: 1.0 | **Date**: 2026-11-02

## Назначение

Гарантировать, что «собрано из этого коммита» означает один и тот же набор
зависимостей и один и тот же образ, а известные уязвимости видны до выпуска.

## Обязательные свойства

| Свойство | Требование |
|---|---|
| Зависимости | зафиксированы lock-файлом; сборка из lock, без разрешения версий на лету |
| Базовые образы | закреплены по digest, не по плавающему тегу |
| Runtime | без компиляторов и заголовков разработки |
| Пользователь | непривилегированный, фиксированный UID/GID |
| Файловая система | read-only, временные каталоги — tmpfs |
| Возможности | `cap_drop: ALL`, `no-new-privileges` |
| Ресурсы | лимиты памяти и CPU заданы |
| Уязвимости | проверка зависимостей и образа до публикации |
| Состав | SBOM формируется и сохраняется с артефактом |

## Ворота выпуска

1. Lock-файл присутствует и не изменялся вне коммита.
2. Две чистые сборки одного коммита дают совпадающий набор зависимостей.
3. Проверка уязвимостей не находит критических или высоких.
4. Образ запускается без root и без сборочных пакетов.
5. SBOM сформирован.

Если проверка недоступна (нет сети, сбой сканера), выпуск **не считается
чистым**: причина называется, решение принимает владелец. Молчаливый пропуск
запрещён.

## Обновления

- Dependabot следит за Python-зависимостями, GitHub Actions и Docker-образами.
- Обновление зависимостей проходит тот же набор тестов и проверок.
- Понижение версии без причины запрещено.

## Запрещено

- `latest` и плавающие теги в production.
- Сборка «на месте» из неустановленных версий.
- Хранение секретов в образе или слое.
- Публикация образа, не прошедшего ворота.
