# Быстрый старт: карточки дома

Порядок обязателен: сначала механика решения проверяется тестами, потом вёрстка в
браузере. Карточка, которая показывает причину, которой нет, вводит в заблуждение
сильнее, чем карточка без причины вообще.

## Часть 1. Проверка механики решения

```bash
make test-block unit/core/test_fsm_decisions.py
```

Ожидаемое поведение:

- после перехода `explain()` отдаёт `outcome` = `on`/`off`, время и причину;
- после отклонения по условию — `outcome` = `denied` с кодом и формулировкой;
- причина **текстом совпадает** с записью в журнале: берём из журнала строку отказа и
  сравниваем с `reason_text`;
- для несуществующего автомата `explain()` возвращает `None`, а не исключение;
- решение не переживает перезапуск (в памяти, не в базе) — это осознанно, а не утечка.

## Часть 2. Проверка снимка состояний

```bash
make test-block unit/core/test_state_snapshot.py
```

Ожидаемое поведение:

- один вызов `get_states` на весь снимок независимо от числа устройств;
- повторное чтение в пределах пяти секунд **не** обращается к дому повторно;
- при недоступном доме `reachable = false`, состояния — последние известные, а не пустые;
- `unavailable` отличается от `off` (иначе не отвечающий светильник выглядит выключенным);
- снимок не отправляет ни одной команды.

## Часть 3. Проверка карточек в тестах

```bash
make test-block unit/webui/test_cards_rendering.py
```

Ожидаемое поведение на подставных данных:

- карточка показывает **название** из манифеста, а идентификатор — мелким шрифтом;
- при отсутствии названия показан идентификатор, без пустой строки;
- карточка показывает состояние и причину; при неизвестных данных пишет «состояние
  неизвестно», а не пустоту;
- комната в карточке устройства **не** выводится;
- у датчика движения текст «есть движение», иконка не термометр;
- у датчика без управления выключателя нет вовсе;
- при `can_control = false` выключателя нет; при `true` — есть;
- при недоступном доме видна отметка «нет связи» и время последних данных;
- в тексте карточек нет строк `Add Device`, `No devices`, `FSM`, `Edit`, `Delete`.

## Часть 4. Проверка в браузере

### 4.1 Состояние появляется само

Открыть панель при горящем свете в гостиной.

Ожидаемое поведение: карточка «Свет над столом» показывает «включено» без перезагрузки;
выключить свет в Home Assistant — через несколько секунд карточка покажет «выключено».

### 4.2 Причина отвечает на вопрос

Днём, при солнце, вызвать движение датчиком (пройти мимо) при выключенном свете.

Ожидаемое поведение: на карточке появляется объяснение в человеческих словах («светло»)
и время («2 минуты назад»). Тот же текст обязан быть в журнале платформы — это
проверка FR-008, и она делается глазами: открыть `/logs` и сравнить формулировку.

### 4.3 Управление с карточки

Нажать «выключить» на карточке.

Ожидаемое поведение: свет гаснет; кнопка не даёт нажать второй раз во время выполнения;
затем карточка показывает «выключено».

### 4.4 Блокировка видна

Сразу после ручного выключения.

Ожидаемое поведение: карточка пишет, что автоматика устройство не трогает и до какого
времени. Через час отметка исчезает сама, без перезагрузки.

### 4.5 Узкий экран

Сузить окно до ширины телефона.

Ожидаемое поведение: карточки в одну колонку; кнопки переносятся отдельной строкой;
текст и кнопки не наезжают друг на друга; размер шрифта не уменьшается.

### 4.6 Дом недоступен

Остановить контейнер Home Assistant на минуту.

Ожидаемое поведение: карточки показывают «нет связи с домом» и время последних данных;
после возврата связи состояния восстанавливаются сами.

## Часть 5. Обновление

```bash
python tools/gen_template_contract.py   # если затронуты шаблоны поведения
bash .ai/scripts/run_checks.sh           # перед коммитом
```

## Что означает «готово»

- в браузере без перезагрузки видно состояние каждого устройства и датчика;
- на карточке написано, почему устройство в этом состоянии, и эта формулировка совпадает
  с журналом;
- свет переключается с карточки, и после ручного действия интерфейс показывает
  блокировку;
- на телефоне карточки читаемы;
- «молча» в интерфейсе не осталось ничего: состояние неизвестно, дом недоступен,
  команда не выполнена — всё написано словами.
