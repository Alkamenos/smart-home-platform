## Notes

- Решения, зафиксированные по итогам опроса пользователя (2026-09-30):
  1. Единый источник устройств — сервис устройств + постоянное хранилище (FR-001…FR-004).
  2. Согласованность «синк ↔ список» включена в объём (US3, FR-019…FR-023).
  3. Удаление устройства добавлено в объём (US4, FR-024…FR-027).
- Пункты, требующие внимания на этапе планирования:
  - FR-014…FR-018 (мгновенное оживление) затрагивают ядро FSM — правки `FSMDefinition`/debounce/таймаутов запрещены конституцией без согласования.
  - FR-009 (идентификация запросов интерфейса) должна сохранить модель доступа из ранее реализованной спеки 004.
- `/speckit-implement` читает состояние чекбоксов как gate и не должен изменять маркеры.
