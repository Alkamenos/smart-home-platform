# Фича «Шторы» (covers) — Пожарная безопасность

## Обзор

Для штор над входной дверью (`door: true`) добавлена возможность настройки **пожарной безопасности**.
Эта функция гарантирует, что штора никогда не закроется полностью, обеспечивая вентиляцию и
возможность эвакуации в случае пожара.

## Параметры

### В манифесте (`instances/leonid_house/manifest.yaml`)

```yaml
features:
  covers:
    covers:
    - id: gostinnaia_pravaia
      name: Штора в гостиной (правая, над дверью)
      cover: cover.shtora_v_gostinnoi_pravaia
      door: true                      # Обязательно для двери
      away_closed_pct: 60             # Насколько закрывать, когда нас нет (60%)
      fire_safety: true               # Включить пожарную безопасность
      fire_safety_min_pct: 20         # Минимальный процент ОТКРЫТИЯ (штора не закроется ниже 20%)
```

### Параметры

| Параметр | Тип | Обязательный | Описание |
|----------|-----|--------------|----------|
| `door` | boolean | да | Признак шторы над дверью |
| `away_closed_pct` | number (0-100) | да | Насколько закрывать штору, когда никого нет дома |
| `fire_safety` | boolean | нет | Включить режим пожарной безопасности (по умолчанию `false`) |
| `fire_safety_min_pct` | number (0-100) | нет | Минимальный процент открытия шторы (по умолчанию `20`) |

## Логика работы

### Без пожарной безопасности (`fire_safety: false`)

| Ситуация | Положение шторы |
|----------|-----------------|
| День + (дома ИЛИ собаки) | 100% (полностью открыта) |
| День + пустой дом | `100 - away_closed_pct`% (например, 40% при `away_closed_pct=60`) |
| Ночь + дома | 0% (полностью закрыта) |
| Ночь + пустой дом | `100 - away_closed_pct`% |

### С пожарной безопасностью (`fire_safety: true`, `fire_safety_min_pct=20`)

| Ситуация | Положение шторы | Пояснение |
|----------|-----------------|-----------|
| День + (дома ИЛИ собаки) | 100% | Полностью открыта |
| День + пустой дом | max(`100 - away_closed_pct`, `fire_safety_min_pct`)% | Не ниже 20% |
| Ночь + дома | 0% | Полностью закрыта (мы можем открыть вручную) |
| Ночь + пустой дом | max(`100 - away_closed_pct`, `fire_safety_min_pct`)% | Не ниже 20% |

**Пример:**
- `away_closed_pct = 60` → позиция закрытия = 40%
- `fire_safety_min_pct = 20` → минимальное открытие = 20%
- Итог: штора закроется до 40% (т.к. 40% > 20%)

**Другой пример:**
- `away_closed_pct = 90` → позиция закрытия = 10%
- `fire_safety_min_pct = 20` → минимальное открытие = 20%
- Итог: штора закроется только до 20% (т.к. `fire_safety` ограничивает)

## Настройка через дашборд

Для дверей с `fire_safety: true` в дашборде настроек появляются дополнительные элементы:

1. **Пожарная безопасность** (toggle) — включение/выключение режима
2. **Мин. открытие, %** (number slider) — настройка минимального процента открытия (0-100)

Эти настройки можно изменять динамически без перезапуска платформы.

## Helpers

Для каждой двери с пожарной безопасностью создаются следующие helpers:

```yaml
input_boolean.cover_<cid>_fire_safety        # Включение пожарной безопасности
input_number.cover_<cid>_fire_safety_min_pct # Минимальный процент открытия (0-100)
```

## Важные замечания

1. **Ночью дома**: Пожарная безопасность не ограничивает закрытие, когда мы дома ночью.
   Предполагается, что в случае необходимости мы можем открыть штору вручную.

2. **Немедленное закрытие при уходе**: При переходе `my_doma: on → off` штора над дверью
   закрывается до настроенного процента с учётом `fire_safety_min_pct`.

3. **Валидация**: Schema проверяет, что `fire_safety_min_pct` находится в диапазоне 0-100
   и не превышает максимально возможную позицию открытия.

4. **Shadow режим**: В режиме `covers_shadow_mode: on` платформа только логирует действия,
   не отправляя команды приводам.

## Примеры использования

### Стандартная настройка (рекомендуется)

```yaml
door: true
away_closed_pct: 60
fire_safety: true
fire_safety_min_pct: 20
```

Результат:
- Днём при отсутствии: штора закрыта на 60% (позиция 40%)
- Ночью при отсутствии: штора закрыта на 60% (позиция 40%)
- Минимальное открытие гарантировано на уровне 20%

### Максимальная безопасность

```yaml
door: true
away_closed_pct: 80
fire_safety: true
fire_safety_min_pct: 50
```

Результат:
- Штора никогда не закроется больше чем на 50% (позиция ≥50%)
- Даже если `away_closed_pct=80`, `fire_safety` ограничит закрытие

### Без пожарной безопасности

```yaml
door: true
away_closed_pct: 60
fire_safety: false  # или не указывать
```

Результат:
- Штора закрывается по стандартной логике без ограничений
