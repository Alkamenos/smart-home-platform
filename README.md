# Smart Home FSM Platform V3

A modern, state-machine based automation platform for smart home systems. This platform provides a robust framework for defining, managing, and executing complex home automation scenarios using finite state machines (FSM). Built with Python 3.10+, it features strict schema validation via Pydantic, declarative configuration support through YAML, structured logging with Loguru, and comprehensive testing capabilities. The platform is designed to be extensible, allowing integration with various smart home devices and protocols through a modular adapter architecture.
