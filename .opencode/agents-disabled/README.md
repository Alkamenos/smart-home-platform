# Отключённые субагенты

**Дата отключения:** 2026-10-11 · **Причина:** тарифное ограничение, не дефект проекта.

## Что произошло

Все четыре агента были прибиты к моделям free tier:

| Агент | Модель |
|---|---|
| `researcher` | `opencode/nemotron-3.5-lightning-free` |
| `test-writer` | `opencode/mimo-v2.6-flash-free` |
| `implementer` | `opencode/space-bunny-free#high` |
| `reviewer` | `opencode/space-bunny-free#high` |

Запуск любого из них падал с ошибкой:

```
Subagent failed: OpenCode's free tier can only be used from within OpenCode
```

Модели в провайдере **включены** (проверено: `space-bunny-free`,
`nemotron-3.5-lightning-free`, `mimo-v2.6-flash-free` — все в списке из 43
разрешённых), но free tier не работает в дочерних сессиях. Это ограничение
тарифа на стороне провайдера, а не ошибка конфигурации `opencode.json`.

## Как вернуть

```bash
git mv .opencode/agents-disabled/*.md .opencode/agents/
```

Файлы перемещены через `git mv`, история сохранена. Ничего не переписывалось —
при смене тарифа вернуть достаточно одной команды.

## Пока агенты отключены

Цикл SDD из `/task` работать не может: роли `researcher` → `test-writer` →
`implementer` → `reviewer` не запускаются. Супервизору остаётся оркестрация
вручную, с ограничением «не писать код и тесты самому».

## Что можно сделать вместо отключения

Переприбить агентов на платные модели того же провайдера — тогда ограничение
free tier перестаёт касаться дочерних сессий:

| Агент | Роль | Что подходит |
|---|---|---|
| `researcher` | чтение и находки с `file:line` | быстрая и дешёвая модель |
| `test-writer` | только тесты, узкий контекст | быстрая и дешёвая модель |
| `implementer` | код по готовым красным тестам | модель посильнее — держит карту из ~20 файлов |
| `reviewer` | поиск дыр в диффе | модель посильнее — читает критично |

Правка — одна строка `model:` в каждом файле. Решение владельца: платить за
вызовы или держать агентов выключенными, пока тариф не сменится.
