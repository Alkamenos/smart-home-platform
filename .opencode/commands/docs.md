description: Поиск документации — сначала библиотеки (docs-mcp-server), потом контекст проекта (ContextQMD)
---

Найди документацию по запросу: $ARGUMENTS

Порядок поиска (остановись, когда получил достаточно материала):

1. **Библиотеки и фреймворки** → инструменты `docs`:
   - `search_docs({library: "<библиотека>", query: "<запрос>"})` — если библиотека уже проиндексирована (`list_libraries()` покажет какие).
   - Если библиотеки нет в индексе — `scrape_docs({library, url})` (однократно), затем повтори поиск. Для быстрого чтения одной страницы — `fetch_url`.
   - Для версии: `version: "5.x"` или точный номер.
2. **Контекст проекта** (`.ai/`: правила, Known Issues, roadmap, workflow) → `contextqmd.search_docs({query, library: "smart-home-ai", mode: "auto"})`, при необходимости `contextqmd.get_doc` для чтения фрагмента.
3. Если оба источника не дали ответа — websearch/webfetch как последний вариант.

Формат ответа (строго):
```
## Ответ
Суть по существу вопроса (2–6 предложений или пример кода).

## Источники
- <URL или path:line> — что взял
```

Правила:
- Цитируй только реально найденный текст, не додумывай API.
- Не грузи страницу целиком — бери релевантный фрагмент (`get_doc` c from_line/max_lines).
- Если документация библиотеки не проиндексирована и скрейп не удался — прямо скажи об этом.
