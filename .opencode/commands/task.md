Выполни задачу по полному pipeline из AGENTS.md / `.ai/00_START_HERE.md`.

Задача: $ARGUMENTS

Порядок (не сокращай):

1. **Исследование** — запусти subagent `researcher` с этой задачей. Дождись его отчёта, не начинай реализацию раньше.
2. **Реализация** — маленькие атомарные изменения в src/, тесты сразу (TDD), type hints и docstrings обязательны.
3. **Параллельно, фоном** — запусти одновременно:
   - subagent `test-writer` с описанием реализованного (дописать тесты в tests/),
   - subagent `reviewer` на текущий diff (background).
4. **Исправь** замечания reviewer с severity critical/major. Minor — по своему усмотрению.
5. **Гейт** — `.ai/scripts/run_checks.sh` (или `make lint && make type-check && make test`). При exit code 1 — исправь и повтори, максимум 2 круга. Если не прошло — остановись и сообщи.
6. **Финал** — краткий отчёт: что сделано, какие тесты добавлены, вердикт ревью, статус гейта.

Ограничения: не коммить сам (хуки и коммит — работа пользователя), не пушь, не трогай `.ai/` и конфиги без явного запроса.
