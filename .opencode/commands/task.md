Выполни задачу по полному pipeline из AGENTS.md / `.ai/00_START_HERE.md`.

Задача: $ARGUMENTS

Порядок (не сокращай):

1. **Исследование** — запусти subagent `researcher` с этой задачей. Дождись его отчёта, не начинай реализацию раньше.
2. **Реализация** — маленькие атомарные изменения в src/, тесты сразу (TDD), type hints и docstrings обязательны.
3. **Параллельно, фоном** — запусти subagent `test-writer` с описанием реализованного: он допишет тесты в tests/ и **сам их запустит**.
4. **Ревью** — после того как `test-writer` закончил, запусти subagent `reviewer` на полный diff (так тесты тоже попадут в ревью). Не запускай его одновременно с тестами.
5. **Исправь** замечания reviewer с severity critical/major. Minor — по своему усмотрению.
6. **Документация** — запусти subagent `docs-writer` с описанием изменения **по логике** (что делает, при каких условиях, что проверено живьём). Он запишет в `.ai/01_PROJECT_STATE.md` / `.ai/02_ARCHITECTURE.md` / `.ai/03_ROADMAP.md`. Правило владельца «Логику — в документацию до коммита».
7. **Гейт** — `.ai/scripts/run_checks.sh` (или `make lint && make type-check && make test`). При exit code 1 — исправь и повтори, максимум 2 круга. Если не прошло — остановись и сообщи.
8. **Финал** — краткий отчёт: что сделано, какие тесты добавлены, вердикт ревью, что записано в `.ai/`, статус гейта.

Боевые задачи (манифест в `deploy/`, поведение живого HA): после гейта запусти
subagent `deploy-checker` для read-only проверки статуса/health/логов платформы.

Ограничения: не коммить сам (хуки и коммит — работа пользователя), не пушь, не трогай `.ai/04_RULES.md` и конфиги без явного запроса.
