# Фича «Шторы» (covers) — Пожарная безопасность и настройки

## Обзор

Для штор над входной дверью (`door: true`) добавлена возможность настройки **пожарной безопасности**.
Эта функция гарантирует, что штора никогда не закроется полностью, обеспечивая вентиляцию и
возможность эвакуации в случае пожара.

Также добавлены три глобальных переключателя для гибкого управления поведением штор:

1. **Закрывать шторы ночью** (`covers_close_night`) — закрывать обычные шторы по расписанию ночью
2. **Закрывать ночью штору над дверью** (`covers_close_door_night`) — закрывать штору над дверью ночью
3. **Закрывать шторы когда нас нет** (`covers_close_away`) — закрывать шторы при отсутствии хозяев

## Параметры

### В манифесте (`instances/leonid_house/manifest.yaml`)

```yaml
features:
  covers:
    enabled: true
    mode: real
    presence_flag: input_boolean.my_doma
    defaults:
      open_time: "08:00"
      close_time: "00:00"
    covers:
    - id: gostinnaia_pravaia
      name: Штора в гостиной (правая, над дверью)
      cover: cover.shtora_v_gostinnoi_pravaia
      door: true                      # Обязательно для двери
      away_closed_pct: 60             # Насколько закрывать, когда нас нет (60%)
      fire_safety: true               # Включить пожарную безопасность
      fire_safety_min_pct: 20         # Минимальный процент ОТКРЫТИЯ (штора не закроется ниже 20%)
```

### Параметры шторы

| Параметр | Тип | Обязательный | Описание |
|----------|-----|--------------|----------|
| `door` | boolean | да | Признак шторы над дверью |
| `away_closed_pct` | number (0-100) | да | Насколько закрывать штору, когда никого нет дома |
| `fire_safety` | boolean | нет | Включить режим пожарной безопасности (по умолчанию `false`) |
| `fire_safety_min_pct` | number (0-100) | нет | Минимальный процент открытия шторы (по умолчанию `20`) |

### Глобальные переключатели (input_boolean)

| Helper | Название | По умолчанию | Описание |
|--------|----------|--------------|----------|
| `input_boolean.covers_close_night` | Закрывать шторы ночью | on | Закрывать обычные шторы в ночное время по расписанию |
| `input_boolean.covers_close_door_night` | Закрывать ночью штору над дверью | on | Закрывать штору над дверью в ночное время |
| `input_boolean.covers_close_away` | Закрывать шторы когда нас нет | on | Закрывать все шторы при отсутствии хозяев (если нет собак) |

## Логика работы

### Обычные шторы (не над дверью)

| Ситуация | `covers_close_night` | `covers_close_away` | Положение шторы |
|----------|---------------------|---------------------|-----------------|
| День + дома | - | - | 100% (открыта) |
| День + пустой дом | - | on | 100% (открыта, если есть собаки) / 0% (закрыта, если нет) |
| Ночь + дома | on | - | 0% (закрыта) |
| Ночь + пустой дом | on | on | 0% (закрыта) |
| Ночь + любые условия | off | off | Не закрывается автоматически |

### Штора над дверью с пожарной безопасностью

#### Без пожарной безопасности (`fire_safety: false`)

| Ситуация | Положение шторы |
|----------|-----------------|
| День + (дома ИЛИ собаки) | 100% (полностью открыта) |
| День + пустой дом | `100 - away_closed_pct`% (например, 40% при `away_closed_pct=60`) |
| Ночь + дома + `covers_close_door_night=on` | 0% (полностью закрыта) |
| Ночь + дома + `covers_close_door_night=off` | Не закрывается |
| Ночь + пустой дом + `covers_close_door_night=on` | `100 - away_closed_pct`% |
| Ночь + пустой дом + `covers_close_door_night=off` | Не закрывается |

#### С пожарной безопасностью (`fire_safety: true`, `fire_safety_min_pct=20`)

| Ситуация | Положение шторы | Пояснение |
|----------|-----------------|-----------|
| День + (дома ИЛИ собаки) | 100% | Полностью открыта |
| День + пустой дом | max(`100 - away_closed_pct`, `fire_safety_min_pct`)% | Не ниже 20% |
| Ночь + дома + `covers_close_door_night=on` | 0% | Полностью закрыта (мы можем открыть вручную) |
| Ночь + дома + `covers_close_door_night=off` | Не закрывается | Настройка отключена |
| Ночь + пустой дом + `covers_close_door_night=on` | max(`100 - away_closed_pct`, `fire_safety_min_pct`)% | Не ниже 20% |
| Ночь + пустой дом + `covers_close_door_night=off` | Не закрывается | Настройка отключена |

**Пример:**
- `away_closed_pct = 60` → позиция закрытия = 40%
- `fire_safety_min_pct = 20` → минимальное открытие = 20%
- Итог: штора закроется до 40% (т.к. 40% > 20%)

**Другой пример:**
- `away_closed_pct = 90` → позиция закрытия = 10%
- `fire_safety_min_pct = 20` → минимальное открытие = 20%
- Итог: штора закроется только до 20% (т.к. `fire_safety` ограничивает)

## Настройка через дашборд

### Глобальная карточка штор

В дашборде настроек (вкладка «🪟 Шторы») находится глобальная карточка с переключателями:

1. **Собаки дома** — наличие собак в доме
2. **Автоматика штор** — общий флаг включения автоматики
3. **Shadow режим** — режим логирования без выполнения команд
4. **Закрывать шторы ночью** — включение ночного закрытия обычных штор
5. **Закрывать ночью штору над дверью** — включение ночного закрытия двери
6. **Закрывать шторы когда нас нет** — закрытие при отсутствии хозяев

### Карточка каждой шторы

Для каждой шторы доступна отдельная карточка с настройками:

- **Автоматика** (toggle) — включить/выключить автоматику этой шторы
- **Закрытие** (select) — «Время» / «Не закрывать»
- **Открытие** (select) — «Время» / «Не открывать»
- **Время закрытия** (datetime) — появляется при выборе «Время»
- **Время открытия** (datetime) — появляется при выборе «Время»
- **Положение** (info) — текущее положение шторы в %

#### Для дверей дополнительно:

- **Закрывать ушедших, %** (number) — насколько закрывать штору при отсутствии
- **Пожарная безопасность** (toggle) — включение режима пожарной безопасности
- **Мин. открытие, %** (number) — минимальный процент открытия (появляется при включении пожарной безопасности)

Эти настройки можно изменять динамически без перезапуска платформы.

## Helpers

### Глобальные helpers

```yaml
input_boolean.dogs_home                 # Собаки дома
input_boolean.feature_covers            # Автоматика штор (общий флаг)
input_boolean.covers_shadow_mode        # Shadow режим
input_boolean.covers_close_night        # Закрывать шторы ночью
input_boolean.covers_close_door_night   # Закрывать ночью штору над дверью
input_boolean.covers_close_away         # Закрывать шторы когда нас нет
```

### Per-shade helpers

Для каждой шторы (<cid> — id из манифеста):

```yaml
input_boolean.cover_<cid>_auto            # Автоматика этой шторы
input_select.cover_<cid>_close            # Режим закрытия ["Время", "Не закрывать"]
input_datetime.cover_<cid>_close_time     # Время закрытия
input_select.cover_<cid>_open             # Режим открытия ["Время", "Не открывать"]
input_datetime.cover_<cid>_open_time      # Время открытия
```

Для дверей дополнительно:

```yaml
input_number.cover_<cid>_away_closed_pct       # Насколько закрывать ушедших (0-100)
input_boolean.cover_<cid>_fire_safety          # Пожарная безопасность (on/off)
input_number.cover_<cid>_fire_safety_min_pct   # Мин. открытие, % (0-100)
```

## Важные замечания

1. **Пожарная безопасность ночью дома**: Когда мы дома ночью, пожарная безопасность не ограничивает
   закрытие шторы над дверью. Предполагается, что в случае необходимости мы можем открыть штору вручную.

2. **Немедленное закрытие при уходе**: При переходе `my_doma: on → off` все авто-шторы закрываются сразу:
   - Обычные: 100% (полностью)
   - Дверь: до `away_closed_pct`% с учётом `fire_safety_min_pct`

3. **Override (ручное вмешательство)**: После ручного изменения положения шторы платформа не трогает
   её ~60 минут. Это позволяет временно переопределить автоматику.

4. **Валидация**: Schema проверяет, что `fire_safety_min_pct` находится в диапазоне 0-100
   и не превышает максимально возможную позицию открытия.

5. **Shadow режим**: В режиме `covers_shadow_mode: on` платформа только логирует действия,
   не отправляя команды приводам. Ручное управление работает всегда.

6. **Анти-цикл**: Команды приводу отправляются не чаще ~2 минут для предотвращения износа.

## Примеры использования

### Стандартная настройка (рекомендуется)

```yaml
door: true
away_closed_pct: 60
fire_safety: true
fire_safety_min_pct: 20
covers_close_door_night: on  # в дашборде
```

Результат:
- Днём при отсутствии: штора закрыта на 60% (позиция 40%)
- Ночью при отсутствии: штора закрыта на 60% (позиция 40%)
- Ночью дома: штора полностью закрыта (0%)
- Минимальное открытие гарантировано на уровне 20%

### Максимальная безопасность

```yaml
door: true
away_closed_pct: 80
fire_safety: true
fire_safety_min_pct: 50
covers_close_door_night: on
```

Результат:
- Штора никогда не закроется больше чем на 50% (позиция ≥50%)
- Даже если `away_closed_pct=80`, `fire_safety` ограничит закрытие

### Гибкое управление без пожарной безопасности

```yaml
door: true
away_closed_pct: 60
fire_safety: false
covers_close_door_night: off  # Не закрывать дверь ночью автоматически
covers_close_away: on         # Но закрывать когда нас нет
```

Результат:
- Днём при отсутствии: штора закрыта на 60%
- Ночью: штора не закрывается автоматически (можно закрыть вручную)
- При уходе: штора закрывается на 60%

### Обычные шторы с отключенным ночным закрытием

```yaml
covers_close_night: off  # в дашборде
covers_close_away: on    # но закрывать когда нас нет
```

Результат:
- Ночью дома: шторы не закрываются автоматически
- При уходе: шторы закрываются
- Днём: шторы открываются по расписанию
