# Аддон Behavioral Platform для Home Assistant

Платформа поведенческой автоматики дома, упакованная как аддон Home Assistant:
установка и обновление из магазина, панель рядом с домом, **без длинного токена**
(доступ к Home Assistant идёт через Supervisor).

## Что нужно

- Home Assistant OS или Supervised (у обычного Docker-хоста аддонов нет — там
  используйте `deploy/docker/docker-compose.prod.yml`).
- Опубликованный образ: `ghcr.io/alkamenos/smart-home-platform-addon-{arch}`.
  Собирается CI по тегу `v*` (`.github/workflows/addon.yml`).

## Установка

1. Настройки → Дополнения → Магазин → «⋮» → Репозитории.
2. Добавить `https://github.com/Alkamenos/smart-home-platform`.
3. Установить «Behavioral Platform» и запустить.

## Настройки

| Опция | По умолчанию | Что значит |
|---|---|---|
| `log_level` | `info` | Уровень журнала платформы |
| `shadow_mode` | `false` | `true` — считать, но не командовать приборами |
| `timezone` | `Asia/Yekaterinburg` | Часовой пояс дома для правил «светло ли» |

## Где лежат данные

- **Конфигурация (манифест):** `/addon_config/config/manifest.yaml`
- **Данные (состояние, ключ шифрования, журнал):** `/addon_config/data/`

Оба каталога входят в резервные копии Home Assistant вместе с аддоном. При первом
запуске манифест сеется из образа (эталонный дом); дальше правится в интерфейсе
платформы.

## Чего пока нет (следующие шаги B79)

- **Ingress** (панель внутри боковой панели Home Assistant): сейчас веб-интерфейс
  открывается по порту `8125`. Для ingress платформе нужно учитывать
  `X-Ingress-Path` и строить относительные ссылки.
- **Мультиархитектурная публикация** (amd64 и aarch64) — в CI уже заложена, нужен
  первый прогон на теге.
- **Автообновление** — поднимать `version` в `config.yaml` вместе с тегом образа.
